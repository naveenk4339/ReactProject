# React Shopping Cart

Simple React (Vite) app with:

- **Login page** – email + password with basic validation (valid email, password ≥ 6 chars). No backend; any valid input logs you in.
- **Home page** – list of shopping items; add items to the cart, adjust quantities with −/+, and see the running **total items** and **total price**.

## Run

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually http://localhost:5173).
